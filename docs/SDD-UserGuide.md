# SDD：校准流程用户指南

本文档说明如何使用 `calibration/calibrate_gui.py` 完成从无宏弹痕到可用 GunData、再到开宏微调的完整流程。启动方式：

```bash
python -m calibration.calibrate_gui
```

---

## 1. 截图与环境准备

1. 找**干净、浅色、纹理少**的墙面，避免强反光与复杂图案。
2. **分辨率**应与游戏一致；工具会按图像尺寸自适应检测参数，但分辨率不一致会导致标注坐标与运行时预期不符。
3. 整匣射击后截图（建议 PNG），保证弹痕完整、清晰。

---

## 2. Round 1：无宏 — 生成初始压枪数组

**目的**：在未开启压枪宏的情况下，根据真实弹痕间距直接生成 `GunData` 中对应配件码的数组（不依赖已有 JSON 中的曲线形状）。

**步骤**：

1. **关闭宏**，使用目标枪械、配件、倍镜与姿势，打完至少一整匣（或足够多发）。
2. 截图并保存。
3. 打开校准 GUI → 选择**枪械、倍镜、枪口、握把、枪托、姿势**（配件组合决定 `acc_code`，见数据格式文档）。
4. 点击 **「加载弹痕图」**，载入截图。
5. （推荐）点击 **「框选区域」**，在弹痕区域拖出 ROI，减少背景干扰后再 **「检测弹孔」**。
6. 若自动检测不准：在画布上 **左键空白处添加**、**左键拖动** 调整、**右键删除** 弹孔；可用 **Shift+拖拽** 框选批量删除。
7. 确认 **「标注顺序 = 开火顺序」**（第一个点的 `shot_num` 对应第 1 发）。可用 **「起始发数」** 从中间某发开始编号（用于部分弹匣等场景）。
8. 点击 **「分析参数」**：右侧显示 Round 1 生成结果（每 tick 值、`chunk_f`、RPM 等）。
9. 点击 **「保存项目」** 得到 `.calibration.json`；可选 **「复制修正参数」** 将 JSON 片段复制到 `_internal/GunData/<枪名>.json` 中对应 `acc_code` 键。

**多轨迹（Round 1）**：若同一张图或多次射击希望综合多条标注轨迹，可 **「+新建」** 轨迹，分别在不同轨迹上标注后点击 **「分析全部轨迹」**：工具会对各轨迹的逐发像素间距取平均，再生成一条综合数组。

---

## 3. Round 2 及以后：开宏 — 迭代修正

**目的**：将已写入 GunData 的参数在实际宏开启状态下跑一轮，根据**残差弹痕**做比例缩放，消除像素与鼠标单位、灵敏度等系统误差。

**步骤**：

1. 将 Round 1（或上一轮）参数写入 `GunData` 并在游戏中 **开启宏**。
2. 保持**相同枪械、配件、倍镜、姿势**（与 JSON 键及 config 灵敏度一致），打完一匣并截图。
3. 在 GUI 中加载本轮截图，标注或检测开宏后的弹痕（同样保证顺序与发数正确）。
4. 点击 **「迭代修正」**：工具从当前 `_internal/GunData/<枪名>.json` 读取 **当前选中 `acc_code`** 的数组，结合 `chunk_f`（由武器射速元数据计算）与残差计算修正比例。
5. 结果会写入 `calibration_project/` 下带时间戳的 `.calibration.json`；按界面提示复制数组替换 GunData。
6. 若残差仍大，可重复 **开宏 → 截图 → 标注 → 迭代修正**。

**多轨迹迭代**：多条轨迹均 ≥2 个弹孔时，迭代会对各轨迹的修正比例 **取平均** 后再应用，提高稳定性。

**起始发数**：若只标注了某一发之后的弹痕，设置 **「起始发数」** 后，迭代可只调整从该发对应的数组下标起的 chunk，其余元素保持原值（见 `IterativeCorrector` 中 `array_offset`）。

---

## 4. 多轨迹支持小结

| 场景 | 操作 |
|------|------|
| Round 1 多条标注 | 「+新建」轨迹 → 各轨迹标注 →「分析全部轨迹」 |
| Round 2 多条残差 | 多轨迹均有足够弹孔 →「迭代修正」自动汇总 |
| 保存/加载 | v3 项目文件含 `trajectories` 数组，可恢复多条轨迹与弹孔 |

---

## 5. 曲线编辑器（`RecoilCurveEditor`）

**作用**：在已有数组（分析或迭代生成）基础上，按 **「每发一个 chunk」** 显示节点（纵轴为该 chunk 内元素之和），拖拽节点可 **按比例缩放该 chunk 内所有 tick 值**。

**操作**：

1. 完成 **「分析参数」** 或 **「迭代修正」** 后，下方曲线区会刷新。
2. 拖拽节点调整某一发的总补偿强度；松开后可点击 **「应用曲线修改」** 将修改写回当前结果面板，便于复制到 GunData。
3. **「重置曲线」** 恢复为最近一次分析/迭代的数组。

适用于细调某一发段、而不希望整段重算数值的场景。

## 7. 准确标注与检测技巧

1. **顺序第一**：标注顺序必须与开火顺序一致；错误顺序会导致整段比例与发号错位。
2. **ROI**：框选仅包含弹痕带，可显著减少误检。
3. **灵敏度**：检测过漏试 **高**；误检多试 **低** 或 **中**（与 `BulletDetector` 预设一致）。
4. **模板图**（若 CLI 或扩展使用）：从截图裁 **15–60px** 弹孔贴图可提高模板匹配成功率；GUI 主流程以单图检测为主。
5. **倍镜与姿势**：`scope_val` 来自 `Config/config.json`；`posture_val` 来自 GunData 的 `none`/`c`/`z`。修改游戏灵敏度后应同步 config，否则 Round 1 与理论对比会偏差。
6. **横向漂移**：若结果中 **水平漂移** 持续偏大，说明存在左右后坐力或视角移动；纯纵向压枪数组无法完全消除，需保证射击时尽量对准墙面、减少移动。

---

## 8. 与 CLI 的关系

`bullet_analysis.py` 可直接作为命令行工具对单张图跑检测与对比（见模块内 `_cli_main`）。日常校准以 GUI 为主；批处理或自动化可调用 CLI。
