================================================================
  PUBG 宏识别工具 — 使用说明
================================================================

【系统要求】
  - Windows 7 / 8 / 10 / 11 (64位)
  - 已安装 罗技 G HUB 驱动 (https://www.logitechg.com/zh-cn/innovation/g-hub.html)
  - 屏幕分辨率: 支持 1920x1080 / 2560x1440 / 1728x1080 等常见分辨率

【快速开始】
  1. 解压 ZIP 到任意目录 (路径不要包含中文和空格)
  2. 确保罗技 G HUB 已安装并运行
  3. 双击「启动.bat」或直接运行「PUBG宏识别工具.exe」
  4. 在主界面选择你的屏幕分辨率
  5. 点击「开始」按钮
  6. 进入游戏，按 Tab 键打开背包触发枪械识别

【操作说明】
  - Tab 键: 打开背包时自动识别枪械和配件
  - 1/2 键: 切换 1 号枪 / 2 号枪
  - 鼠标右键: 开镜 (长按/点击模式可在界面设置)
  - 鼠标左键: 开镜状态下自动压枪
  - Z 键: 切换为趴下姿态
  - C 键: 切换为蹲下姿态
  - Space: 恢复站立姿态

【配置文件】
  - Config/config.json    — 分辨率、灵敏度、压枪版本等设置
  - Config/hud_config.json — HUD 浮窗位置和样式设置
  
  提示: 配置会在界面中修改后自动保存，一般无需手动编辑。

【常见问题】
  Q: 启动后提示「未安装ghub或者lgs驱动」？
  A: 请安装罗技 G HUB 驱动，安装后重启电脑再运行本工具。

  Q: 枪械识别不准确？
  A: 请确认已正确选择屏幕分辨率，且游戏画面没有被遮挡。

  Q: 程序闪退？
  A: 查看 logs/ 目录下的日志文件，反馈给开发者。

【目录结构】
  PUBG宏识别工具.exe     — 主程序
  启动.bat               — 快捷启动脚本
  Config/                — 配置文件目录
  _internal/             — 运行时资源 (请勿删除或修改)
    GunData/             — 弹道数据
    data/firearms/       — 枪械识别模板
    ghub_device_GHUB.dll — 罗技驱动接口
  logs/                  — 运行日志
