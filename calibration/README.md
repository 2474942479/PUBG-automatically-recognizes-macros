# PUBG 弹痕分析工具 v3

## 简介

通过分析弹痕截图，计算实际后坐力与宏参数的偏差，输出修正后的压枪参数。

## 快速开始

```bash
# 启动 GUI
python -m calibration.calibrate_gui

# CLI 模式 (快速分析)
python -m calibration.bullet_analysis screenshot.png --gun m762 --acc A0B0C0
```

## 操作流程

### Round 1: 首次校准 (不开宏)

1. 在游戏中找一面干净的墙壁
2. **不开启宏**, 用目标枪械打完整个弹匣
3. 截图保存为 PNG (分辨率与游戏一致)
4. 打开 GUI 工具
5. 选择对应的枪械、配件、倍镜、姿势
6. 点击**「加载弹痕图」**
7. **推荐**: 点击**「框选区域」**拖出弹痕所在区域 (大幅减少误检)
8. 点击**「分析」**
9. 检查检测结果:
   - 自动检测的弹孔以彩色圆圈标注
   - 如有误检/漏检: **右键**添加弹孔, **左键拖拽**调整位置, **右键菜单**删除
   - 修改弹孔后右侧结果自动刷新
10. 确认后点击**「保存项目」**(保存为 `.calibration.json`)
11. 点击**「复制修正参数」**→ 粘贴到 `_internal/GunData/枪名.json` 中对应条目

### Round 2+: 迭代修正 (开宏后微调)

1. 使用 Round 1 的修正参数开启宏
2. 同枪/同配件/同倍镜/同姿势, 打完整个弹匣并截图
3. 点击**「迭代修正」**
4. 选择上一轮保存的 `.calibration.json` 项目文件
5. 选择本轮弹痕截图
6. 工具自动: 加载配置 → 检测弹孔 → 计算残差 → 输出微调参数
7. 结果自动保存为新的 `.calibration.json`

### 多组比对

同一枪械/配件多次射击, 收集多组数据取平均:

1. 完成一次分析后, 点击**「添加到组」**
2. 重复分析不同截图, 逐一添加
3. 或使用**「批量加载」**选择多个 `.calibration.json`
4. 点击**「交叉比对」**→ 统计分析 + 最优参数

## 检测模式

| 模式 | 触发条件 | 适用场景 |
|------|---------|---------|
| 单图自适应 | 不加载模板, 不加载基线图 | **默认推荐**, 适合大多数情况 |
| 模板匹配 | 加载弹孔模板 | 弹孔特征明显但自适应漏检时 |
| 双图差分 | CLI 模式提供 --base 参数 | 有空墙参考图时精度最高 |

### 制作弹孔模板

1. 从弹痕截图中裁剪**一个清晰的弹孔**
2. 尺寸约 15~50px 的正方形
3. 紧贴弹孔边缘, 包含弹孔 + 一圈背景
4. 保存为 PNG

## 概念说明

### 比值 (ratio)

`ratio = 实际弹孔间距 / 理论补偿间距`

- **> 1**: 宏补偿不足 → 需要**增大**参数 (屏幕上弹孔比预期分散)
- **< 1**: 宏补偿过多 → 需要**减小**参数
- **≈ 1**: 参数准确

### chunk_size

GunData JSON 中的数组每 N 个元素对应一发子弹的补偿:

```
子弹1的补偿 = array[0] + array[1] + ... + array[N-1]
子弹2的补偿 = array[N] + array[N+1] + ... + array[2N-1]
```

每个元素执行一次 `mouse_move(0, round(posture * (value * scope)))`, 间隔 9ms。
chunk_size 由工具自动计算: `N = len(array) / (弹孔数 - 1)`。

### scope_val (倍镜灵敏度系数)

来自 `Config/config.json` 的 `sensitivity` 字段:

```json
{
  "sensitivity": {
    "none": 3.4,
    "hongdian": 3.4,
    "2bei": 3.4,
    ...
  }
}
```

不同倍镜下鼠标灵敏度不同, 该系数用于将数组值转换为实际像素移动量。

### pose_val (姿势倍率)

来自 GunData JSON 文件:

```json
{
  "none": 1.0,    // 站立
  "c": 0.85,      // 蹲下
  "z": 0.7        // 趴下
}
```

### acc_code (配件编码)

格式: `A{枪口}B{握把}C{枪托}`, 每个位置是一个数字编码:

- 枪口: 0=无, 5=步枪补偿器, 6=步枪消焰器, 9=消音器...
- 握把: 0=无, 1=半截式, 2=拇指, 3=直角, 4=垂直
- 枪托: 0=无, 1=战术枪托, 2=重型枪托...

## 检测优化建议

1. **灵敏度选择**
   - 弹孔清晰: 用「低」→ 精准
   - 弹孔模糊/墙面纹理多: 用「高」→ 检出多

2. **框选区域 (ROI)**
   - 点击「框选区域」→ 在画布上拖出矩形
   - 仅分析框内区域, 过滤 90% 噪声

3. **使用模板**
   - 裁剪一个弹孔小图作为模板
   - 加载后自动使用模板匹配模式

4. **查看检测过程**
   - 点击「检测过程」查看:
     - SimpleBlobDetector 参数
     - 中值滤波各尺度结果
     - NMS / 噪声过滤细节

## 常见问题

### 检测不到弹孔

- 墙面太暗 / 弹孔不明显 → 调灵敏度为「高」
- 截图分辨率很高 (4K) → 工具自动适配, 无需特殊设置
- 背景干扰太多 → 使用「框选区域」
- 实在不行 → 手工标注 (右键添加弹孔)

### 检测到太多噪点

- 调灵敏度为「低」
- 使用「框选区域」限定范围
- 手动删除误检点 (右键菜单 → 删除)

### 数据单位不对

所有像素值都基于截图的实际分辨率。理论值通过 `raw_value × scope_val × pose_val` 转换为像素。

### 修正参数怎么用

将「复制修正参数」的内容粘贴到 `_internal/GunData/枪名.json` 中, 替换对应的 `A#B#C#` 条目。

### 迭代到什么程度算好

残差(每发弹孔偏移量)低于 3px 即可认为参数已足够准确。

## 文件说明

| 文件 | 说明 |
|------|------|
| `bullet_analysis.py` | 核心分析模块 (检测/排序/对比/修正/迭代/多组) |
| `calibrate_gui.py` | GUI 工具主程序 |
| `.calibration.json` | 项目文件 (弹孔+配置+结果, 一个文件包含全部状态) |

## CLI 用法

```bash
# 单图自适应
python -m calibration.bullet_analysis shot.png --gun m762

# 使用模板
python -m calibration.bullet_analysis shot.png --template hole.png --gun m762

# 高灵敏度 + 调试输出
python -m calibration.bullet_analysis shot.png --gun m762 --sensitivity high --debug

# 指定倍镜/姿势
python -m calibration.bullet_analysis shot.png --gun m762 --scope 3.4 --posture 0.85
```
