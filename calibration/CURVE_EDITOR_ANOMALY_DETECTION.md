# 曲线编辑器 - 异常值检测功能说明

## 🎯 功能概述

增强版曲线编辑器现已支持**自动识别异常值**，帮助你快速发现压枪数据中的问题点。

## ✨ 新增特性

### 1. 自动异常检测

系统会自动检测以下三类异常：

#### 🔴 严重异常 - 反向值 (Reverse)
- **定义**: 当前发数的补偿值与前后邻居符号相反
- **示例**: 前发=5.0, 当前=-3.0, 后发=4.0
- **影响**: 会导致鼠标反向移动，严重影响压枪效果
- **标记**: 红色节点 + ↕ 图标

#### 🟠 中等异常 - 突变值 (Spike)
- **定义**: 偏离均值超过2.5倍标准差
- **示例**: 平均值为5.0，某发突然变成20.0
- **影响**: 导致弹道突然偏移
- **标记**: 橙色节点 + ▲ 图标

#### 🟡 轻微异常 - 孤立零值 (Zero)
- **定义**: 前后都有非零值，但当前为零
- **示例**: [5.0, 0.0, 4.0]
- **影响**: 可能导致该发子弹无补偿
- **标记**: 浅黄色节点 + ○ 图标

### 2. 可视化展示

- **正常节点**: 蓝色圆圈
- **已修改节点**: 黄色圆圈
- **异常节点**: 
  - 红色 (严重)
  - 橙色 (中等)
  - 浅黄色 (轻微)
- **异常连线**: 红色虚线连接异常区间
- **零线参考**: 灰色虚线标示零点位置

### 3. 交互式操作

#### 查看异常详情
1. 点击 **"隐藏异常标记"** 按钮
2. 下方会显示异常信息面板
3. 表格列出所有异常的：
   - 发数编号
   - 异常类型
   - 详细描述
   - 严重程度

#### 修正异常值
1. 将鼠标悬停在异常节点上
2. 工具提示会显示异常原因
3. **拖拽节点**调整数值
4. 调整后颜色变为黄色（已修改）
5. 点击 **"应用曲线修改"** 保存更改

## 💡 实用技巧

### 1. 判断是否需要修正
- **严重异常 (红色)**: 必须修正，会严重影响压枪
- **中等异常 (橙色)**: 建议修正，可能影响稳定性
- **轻微异常 (黄色)**: 可选修正，视具体情况而定

### 2. 修正策略
```python
# 修正前
[5.0, 5.0, -3.0, 5.0, 5.0]  # 第3发反向

# 修正后 (拖拽第3发节点到正值)
[5.0, 5.0, 5.0, 5.0, 5.0]  # 平滑过渡
```

### 3. 批量修正
- 按住节点拖拽可连续调整
- 每次拖动实时更新底层数组
- 修改过的节点会高亮显示

### 4. 对比原始数据
- 点击"重置曲线"恢复到上次分析结果
- 方便对比修改前后的差异

## 🔍 异常检测算法

### 反向检测
```python
if current * average(prev, next) < 0 and abs(current) > 2:
    mark_as_reverse()
```

### 突变检测  
```python
deviation = abs(current - mean) / std
if deviation > 2.5:
    if deviation > 4:
        severity = 'high'
    else:
        severity = 'medium'
```

### 零值检测
```python
if current == 0 and (prev != 0 or next != 0):
    mark_as_isolated_zero()
```

## ⚙️ 配置说明

异常检测参数可在代码中调整：

```python
# 在 _detect_anomalies() 方法中
std_threshold = 2.5  # 突变阈值（倍数标准差）
reverse_min_abs = 2  # 反向最小绝对值
```

## 📝 注意事项

1. **异常不一定是错误**: 某些枪械的后坐力模式本身就有波动
2. **结合弹痕判断**: 异常值对应实际弹痕是否分散
3. **小幅度调整**: 避免过度修正导致新的问题
4. **保存备份**: 修正前建议保存原始JSON文件

## 🐛 常见问题

**Q: 为什么我的数据有很多异常？**
A: 可能是校准不准确或射击不稳定，建议重新拍摄弹痕并标注。

**Q: 异常值可以忽略吗？**
A: 轻微异常可以接受，但严重异常（红色）必须修正。

**Q: 如何判断修正是否合理？**
A: 修正后曲线应该相对平滑，没有剧烈波动，且符合枪械后坐力特性。

**Q: 能否关闭异常检测？**
A: 可以点击"隐藏异常标记"按钮切换显示/隐藏。
